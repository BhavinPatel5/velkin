# @velkin/react

React wrappers for `@velkin/ui`. Version **0.1.0**.

## Install

```bash
npm install @velkin/ui @velkin/react lit @lit/react
```

```tsx
import { VuThemeProvider } from "@velkin/react/theme-provider";
import { VuButton } from "@velkin/react/button";
```

Import each wrapper from its subpath. React events use `onVu*` and payloads live on `e.detail`.
