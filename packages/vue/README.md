# @velkin/vue

Vue wrappers for `@velkin/ui`. Version **0.1.0**.

## Install

```bash
npm install @velkin/ui @velkin/vue lit
```

```vue
<script setup lang="ts">
import VuButton from "@velkin/vue/button";
</script>

<template>
  <VuButton variant="solid">Save</VuButton>
</template>
```

Import each wrapper from its subpath. Listen with `@vu-*` event names.
