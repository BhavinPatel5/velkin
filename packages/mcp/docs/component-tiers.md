# Component tiers

Velkin uses open-core licensing.

| Tier | Package | License |
|------|---------|---------|
| Free | `@velkin/ui`, `@velkin/react`, `@velkin/vue` | MIT |
| Pro | `@velkin/ui-pro`, `@velkin/react-pro` | Commercial |

Use `velkin_components` with `tier: "pro"` to list Pro-only entries. Pricing and license terms: [velkinui.com/pricing](https://velkinui.com/pricing).
