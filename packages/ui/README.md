# @velkin/ui

Lit custom elements for Velkin UI (`vu-*` tags). Version **0.1.0**.

## Install

```bash
npm install @velkin/ui lit
```

```ts
import "@velkin/ui/theme-provider";
import "@velkin/ui/button";
```

Import each component from its subpath. Do not use the package root export in applications.
